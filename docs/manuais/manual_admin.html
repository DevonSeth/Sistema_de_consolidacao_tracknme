Visão geral

O administrador cuida de alimentar a única informação que o sistema não consegue obter sozinho: pendências de instalação e remoção de rastreador veicular. Tudo mais — incidentes de manutenção, situação do equipamento no Track N'Me, situação do associado na cooperativa (SGA), cálculo de urgência, abertura/fechamento automático — o sistema já resolve sozinho.

Em uma frase: o administrador só cuida de "quem precisa instalar ou tirar um rastreador"; o resto é automático.

Onde isso entra na esteira completa

Todo dia, o sistema baixa os relatórios do Track N'Me, aplica o motor de regras de Manutenção, lê a aba Instalação-Remoção que você preenche e cruza com o SGA, calcula a urgência (1 a 5) e publica a fila pro atendimento em Tratativas. A sua responsabilidade termina depois de cadastrar a linha corretamente — o resto (contato, ligação, encaminhamento) é com o atendimento (ver Manual do Operador).

Como cadastrar uma linha

Ferramenta: Google Sheets, planilha "Administrador", aba "Instalação-Remoção" — a única aba dessa planilha que você edita (as outras duas, Incidentes e Rastreadores Ativos, são escritas automaticamente pelo sistema a cada execução — editar ali é apagado no ciclo seguinte).

Quando cadastrar: assim que uma pendência de instalação ou remoção for recebida — o cadastro é o que faz a pendência existir pro sistema, não espere confirmação de nada. Adicione sempre uma linha nova no final da aba, nunca no meio, nunca sobrescrevendo (ver regra 1 a seguir).

Os 3 campos que realmente travam tudo

ColunaPor quê
ChassiIdentificador real do veículo pro sistema (nunca a placa — ver seção de regras). Sem chassi certo, a pendência fica invisível pro cálculo de urgência.
ServiçoPrecisa deixar claro "Instalação" ou "Retirada/Remoção" — o sistema procura essas ideias no texto.
Data contratoSó pra instalação — é a partir dela que a urgência é calculada.

Os demais campos (telefone, endereço, dados do veículo) melhoram a qualidade do atendimento, mas não travam o cálculo — com destaque pro celular, que é o único telefone usado pelo contato automático (ver regra 2).

Por que CHASSI, nunca PLACA

O sistema usa exclusivamente o chassi pra identificar um veículo de verdade — a placa é só pra leitura humana. Placa pode ficar vazia, mudar de formato, ter erro de digitação; o chassi é um dado imutável. Se só tiver a placa, é melhor esperar descobrir o chassi antes de cadastrar do que cadastrar sem ele.

As 3 regras inegociáveis

1
Nunca apague uma linha antiga. A aba é um histórico que só cresce. Se um dado mudou, insira uma linha nova com o mesmo Chassi — o sistema sempre usa a linha mais recente daquele chassi e ignora as anteriores no processamento.
2
celular é o único telefone do contato automático, sem plano B. Se estiver vazio, a pendência vira "sem telefone" mesmo com Celular Aux/ Telefone Comercial preenchidos — proposital, evita contatar o número errado.
3
Chassi precisa ser exato e consistente entre linhas do mesmo veículo — um espaço a mais ou uma letra diferente faz o sistema achar que são dois veículos. Copie de uma fonte confiável (ex: o próprio Track N'Me) em vez de digitar de cabeça.

O que o sistema faz sozinho a partir daqui

Você não precisa fazer nada disto manualmente:

  1. Cruza cada linha com o SGA (situação ao vivo do associado/veículo) e com Rastreadores Ativos (Track N'Me).
  2. Decide se a pendência já "nasceu" de verdade — uma remoção só vira pendência ativa depois que o SGA confirmar INATIVO pelo menos uma vez.
  3. Calcula a urgência (1 a 5) combinando dias em aberto, risco do veículo (moto 300cc+, FIPE alto, modelo muito roubado) e divergências.
  4. Nunca precisa ser avisado quando uma pendência é resolvida — quem confirma isso é o atendimento.

Exemplo completo — remoção do cadastro à resolução

Chassi = 9BWZZZ377VT004251, Serviço = Retirada

Dia 1
Você cadastra a linha. O veículo ainda está ATIVO no SGA — a pendência ainda não "nasceu" de verdade.
Dia 15
O SGA passa a mostrar INATIVO. A partir daqui o sistema conta os dias — não desde o dia 1 do cadastro.
Dia 20
Urgência nível 1 (Normal) — já aparece em Tratativas, célula verde.
Dia 30
Urgência sobe pra nível 3 (Alta) — célula amarela.
Dia 40
Urgência sobe pra nível 5 (Urgente) — célula vermelha, topo da fila.
Dia 45+
Congela em nível 5 até alguém resolver. O atendimento marca Finalizado depois de confirmar a retirada por fora.

Instalação segue o mesmo princípio, só que o prazo conta a partir da Data contrato (não do SGA), e a conclusão é automática: o sistema vê o equipamento em "Rastreadores Ativos" e fecha sozinho, sem precisar de Finalizado manual.

Perguntas frequentes

E se eu errar um dado depois de já ter cadastrado a linha?
Insira uma linha nova com o mesmo Chassi e o dado corrigido — não edite a linha errada.
Preciso avisar alguém quando terminar de cadastrar uma linha?
Não. O sistema lê a aba inteira a cada execução automática.
O sistema mostra pra mim quando uma pendência foi resolvida?
Não diretamente — quem acompanha é o atendimento. Peça pra consultarem Tratativas/Encaminhar pra Puma pelo chassi.
Por que uma remoção cadastrada há semanas ainda não apareceu pro atendimento?
O motivo mais comum: o SGA ainda mostra o veículo como ATIVO — ver o exemplo acima. A pendência existe na sua aba, mas ainda não "nasceu" pro sistema.
