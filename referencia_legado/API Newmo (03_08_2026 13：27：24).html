Mensagem

Operações relacionadas a mensagem

Envia uma mensagem para um destinatário. Para canais Oficiais META é necessário ter uma janela de conversa aberta nas últimas 24 horas.

Parameters

No parameters

Request body

Envia uma mensagem

Examples: 
{
  "canal": "d3582101-c4c9-5f33-960e-da851e500fa9",
  "destinatario": "5521988887777",
  "abrirAtendimento": true,
  "setor": 1,
  "bot": false,
  "mensagem": {
    "tipo": "texto",
    "texto": "Exemplo de mensagem via API",
    "idResposta": 1
  }
}
Example Description

Envia uma mensagem de texto e abre um atendimento para o setor '1'

Responses

CodeDescriptionLinks
200

Successful operation

Media type
Controls Accept header.
{
  "erro": false,
  "atendimentoId": 1,
  "mensagemId": 1,
  "resultado": {
    "cod": 1,
    "mensagem": "Mensagem enviada com sucesso"
  }
}
No links

Bad Request

{
  "erro": true,
